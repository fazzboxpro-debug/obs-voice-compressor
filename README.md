# Voice Compressor 0.1.4

0.1.4では「使い方・ヘルプ」ボタンと各設定のマウス説明を追加しました。
設定名を初めて使う人向けに変更しましたが、保存済みの設定値は引き継がれます。

0.1.3ではライブメーターを最前面表示にし、OBSのパラメーターを操作しても隠れないようにしました。
メーターは他の通常ウィンドウより前面に表示されます。不要なときは最小化または閉じてください。

0.1.1では、プリセットボタンの処理中に設定画面を再構築していた不具合を修正しました。
旧版を利用中の場合はOBSを終了し、この版の `Install.cmd` で上書きしてから再起動してください。
フィルターIDと設定項目は同じなので、保存済み設定を引き継げます。

Windows x64 / OBS Studio 32.2.2向けの音声フィルタープラグインです。
VSTではなく、OBSの「音声フィルタ」に直接追加します。

## 導入

1. ZIPをフォルダーにすべて展開します。
2. OBSを終了します。
3. `Install.cmd` をダブルクリックし、Windowsの管理者権限確認を許可します。
4. OBSを開き、音声ミキサーのマイクのメニューから「フィルタ」を開きます。
5. 音声フィルタの「＋」から **Voice Compressor（音声コンプレッサー）** を選びます。

インストール先は `C:\ProgramData\obs-studio\plugins\voice-compressor` です。
手動の場合は `package` 内の `voice-compressor` フォルダーを、同じ `plugins` フォルダーへコピーします。
既存版がある場合、インストーラーは `C:\ProgramData\obs-studio\voice-compressor-backups` にバックアップします。
ポータブル版OBS・ARM64版はこの導入手順の対象外です。

削除する場合はOBSを終了し、上記の `voice-compressor` フォルダーだけを削除します。
本ZIPにはソースコードも含まれるので、配布時にはZIP全体を渡してください。

## 最初の調整

「プリセット：自然な声」から始めます。「ライブメーターを開く」を押し、普段の声で話します。
大きめの声で GAIN REDUCTION が3～6 dB程度になるよう、圧縮を始める音量を調整します。
小さい音量のマイクでは、圧縮を始める音量をさらに下げないと圧縮されません。
処理後の音量は初期値0 dB。必要な分だけ上げ、OUTPUTが0 dBFSに達しないようにします。
比較するときはOBSのフィルタの目のアイコンで有効・無効を切り替えます。

| 設定 | 役割 |
|---|---|
| 圧縮を始める音量 | 圧縮を始める入力音量 |
| 音を抑える強さ | しきい値を超えた音量の圧縮比 |
| 抑え始める速さ | 圧縮がかかる速さ |
| 元に戻る速さ | 圧縮が戻る速さ |
| 効き始めのなめらかさ | 圧縮開始付近のなめらかさ |
| 処理後の音量 | 処理音だけの音量補正 |
| 処理音を混ぜる割合 | 原音と圧縮音を混ぜる割合。100%が圧縮音のみ |
| 低音への反応を抑える | 低音で過剰に圧縮されるのを抑える。音そのものの低音は削らない |

左右・各チャンネルで同じ圧縮量を使い、音像の偏りを抑えます。最大8チャンネル対応。
メーターは入力ピーク・出力ピーク・圧縮量を表示し、約30回/秒で更新します。
設定画面とメーターは日本語・英語・中国語（簡体字・繁体字）に対応しています。
OBSの「設定 → 一般 → 言語」で言語を選び、OBSを再起動すると切り替わります。
すでに追加したフィルターの名前はOBSに保存されているため、自動では変わりません。必要なら名前を変更してください。
プリセットは全設定を置き換えます。処理後の音量はどちらのプリセットも0 dBです。

## バージョン0.1.4の範囲

- 先読みなしのピーク型コンプレッサーです。急な大音量を完全に止めるリミッターではありません。
- 必要なら、このフィルターの後ろにOBS標準のリミッターを追加してください。
- 自動音量補正、外部サイドチェイン、独自プリセット保存は未搭載。設定はOBSが保存します。
- OBS 32.2.2の実ライブラリを使ったテストに合格。通常のOBS画面でのマイク試聴・長時間配信は未検証です。
- インストーラー自体の実行は未実施です。署名・Microsoft Store用パッケージ・Store審査は未対応です。

## ソースコードとビルド

自作コードは `src`、テストは `tests`、翻訳は `data/locale` にあります。
使用したOBS 32.2.2の公式ヘッダーを `vendor/obs-sdk` に同梱しています。
Windows x64、Python 3.10以降、Zig 0.14.1、OBS Studio 32.2.2で、以下を実行します。

```powershell
python build.py --zig C:\tools\zig\zig.exe --test
```

OBSが標準の場所にない場合は `--obs "D:\Apps\obs-studio"` を付けます。
Zigは https://ziglang.org/download/ から入手できます。
OBSのインポートライブラリはインストール済みの `obs.dll` のエクスポートから生成します。
成果物は `package/voice-compressor` に出力します。OBS本体のDLLは同梱しません。
`--test` はテスト用メーターを短時間開きます。ビルド用フォルダーに画像とテスト実行ファイルを出力します。
